## Galaxy 설치 / 업데이트 방법

> Galaxy의 **보안 위험 자동 차단**이 켜져 있으면 GitHub에서 내려받은 APK 설치 및 업데이트가 차단될 수 있습니다. 설치가 필요한 경우에만 잠시 끄고, 설치 후 다시 켜는 것을 권장합니다. Samsung 및 One UI 버전에 따라 메뉴 이름과 위치가 조금 다를 수 있습니다.

## Galaxy 처음 설치

1. 이 저장소의 **공식 GitHub Release**에서 최신 `daejeon-transport-alarm.apk`를 다운로드합니다.
2. 설치가 차단되면 **설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단**으로 이동해 설치하는 동안만 잠시 끕니다.
3. Android가 요구하면 다운로드에 사용한 브라우저 또는 파일 앱의 **이 출처의 앱 설치 허용**을 켭니다. 이 설정은 보안 위험 자동 차단과 서로 다른 설정입니다.
4. `daejeon-transport-alarm.apk`를 엽니다.
5. Galaxy에서 **앱 설치가 권장되지 않음** 화면이 나오면, 공식 Release에서 받은 대전교통 배차 알람 APK이고 파일명이 맞는지 확인한 뒤 **무시하고 설치**를 선택하면 설치를 계속할 수 있습니다.
6. 설치가 완료되면 앱을 실행합니다.
7. 보안 위험 자동 차단을 잠시 껐다면 다시 켜는 것을 권장합니다.

아무 APK나 경고를 무시하고 설치하지 마세요. 반드시 이 저장소의 공식 Release인지, 앱 이름과 파일명이 올바른지 확인한 경우에만 진행하세요.

## 기존 앱 업데이트

1. 대전교통 배차 알람을 실행합니다.
2. **설정 → 앱 업데이트**로 이동합니다.
3. **업데이트 다운로드**를 눌러 APK 다운로드와 검증을 완료합니다.
4. 앱에 표시되는 **Galaxy 설치 전 확인** 안내를 읽습니다.
5. 필요하면 보안 위험 자동 차단과 이 출처의 앱 설치 허용을 각각 확인합니다.
6. **검증된 업데이트 설치**를 눌러 Android 설치 화면을 진행합니다.
7. **앱 설치가 권장되지 않음** 화면이 나오면 공식 업데이트 APK인지 확인한 뒤 **무시하고 설치**를 선택할 수 있습니다.
8. 설치가 완료되면 기존 앱 데이터와 예약은 그대로 유지됩니다.
9. 보안 위험 자동 차단을 잠시 껐다면 다시 켜는 것을 권장합니다.

앱 내부 업데이트를 사용할 수 있으므로 기존 사용자는 GitHub에서 APK를 매번 직접 받을 필요가 없습니다.

## Google Play Protect 안내

GitHub에서 직접 배포하는 APK는 Google Play Protect의 추가 확인 대상이 될 수 있으며 문구는 Android, One UI 및 Play Protect 버전에 따라 달라질 수 있습니다.

1. 이 저장소의 공식 GitHub Release APK인지 먼저 확인합니다.
2. 화면에 **세부정보 더보기** 또는 유사한 항목이 있으면 내용을 확인합니다.
3. 설치를 계속할 수 있는 선택지가 표시되더라도 공식 대전교통 배차 알람 APK라고 확인한 경우에만 진행합니다.

**Android 이전 버전에 맞게 개발됨** 또는 최신 개인정보 보호 기능이 없다는 경고가 대전교통 배차 알람에서 실제로 표시된다면 일반적인 설치 단계로 우회하지 말고 해당 앱 버전을 관리자에게 알려주세요. 이 경고는 일반적인 GitHub 외부 APK 안내와 별개로 앱의 `targetSdk` 상태를 점검해야 하는 신호입니다.

## 앱 내부 업데이트 보안 검증

앱은 내려받은 APK를 Android 설치 화면에 전달하기 전에 다음 항목을 모두 확인합니다.

- 매니페스트에 게시된 SHA-256과 실제 APK 해시 일치
- 기존 앱과 다운로드 APK의 패키지 이름 일치
- 다운로드 APK의 버전이 현재 버전보다 높고 게시 정보와 일치
- 기존 설치 앱과 다운로드 APK의 공식 서명 인증서 일치

보안 위험 자동 차단을 잠시 끄는 것은 APK 검증을 생략한다는 뜻이 아닙니다. 앱 내부 업데이트는 위 검증을 모두 통과한 APK만 Android 시스템 설치 화면으로 전달합니다.
